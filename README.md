# 🧮 Java Calculator – Internship Task 1

A simple **Java console calculator** built as part of the Java Developer Internship.  
It supports basic arithmetic operations: addition, subtraction, multiplication, and division (with division‑by‑zero handling).  

## ▶️ Run Instructions
1. Clone the repo: `git clone https://github.com/Lokesh-github07/java-calculator.git`
2. Compile: `javac src/*.java`
3. Execute: `java src.Main`

## 📂 Structure
- `Calculator.java` → arithmetic methods
